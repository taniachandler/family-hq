# Family HQ Setup: a Claude skill

This skill has Claude interview you about your family, build a fair chore chart with you, walk you through putting Family HQ online, and hand you a link that fills it all in.

## Add it to Claude

- **Claude app or claude.ai:** zip the `family-hq-setup` folder, then go to **Settings → Capabilities → Skills → Upload skill** and choose the zip.
- **Claude Code:** copy the `family-hq-setup` folder into `~/.claude/skills/`.

Then say: **"Set up Family HQ for my family."**
